data exposure Report 01

One Attacker Scrapes Salesforce and ServiceNow

Researchers uncovered the City Forum campaign, in which a single attacker-controlled server has systematically scraped Salesforce Experience Cloud and ServiceNow customer portals since at least March 2025. The attacker uses a purpose-built Go tool to query Salesforce Aura, Lightning Web Runtime UI APIs, and ServiceNow search endpoints. One victim recorded more than 560,000 requests from the same infrastructure. The campaign does not rely on software vulnerabilities; instead, it exploits overly permissive guest-user permissions that unintentionally make enterprise records publicly accessible. Organizations should audit guest profiles, restrict object and field access, disable unnecessary public APIs, and monitor anonymous portal activity.

AI prompt injection Report 02

AI Mind Viruses Spread Between Agents

Security researchers demonstrated a new class of attacks called AI mind viruses, where malicious instructions embedded in seemingly legitimate content can spread between interconnected AI agents. An infected agent may store the instructions in persistent memory, shared databases, or generated content, allowing the malicious prompt to reach other agents that later process the contaminated information. This creates the potential for self-propagating indirect prompt injection across multi-agent environments without exploiting traditional software vulnerabilities. The research highlights risks for enterprises deploying autonomous AI workflows. Organizations should isolate agent memory, sanitize external content, enforce least-privilege tool access, monitor agent-to-agent interactions, and require approval for sensitive actions.

ransomware extortion Report 03

Ransom Busters Extorts Ransomware Victims Twice

Researchers uncovered a threat actor calling itself Ransom Busters, which contacts ransomware victims and claims to have compromised ransomware groups' administrative servers. It offers to recover files and permanently delete stolen data for payments between $20,000 and $60,000. Investigations found significant similarities between Ransom Busters and ransomware intrusions involving DragonForce, Settra, and Anubis, suggesting the supposed rescuer may actually be a ransomware affiliate seeking additional payments. Common tools and infrastructure were identified across incidents. Researchers warn that paying such actors provides no guarantee that stolen information or backups will actually be deleted.
