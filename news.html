remote exploitation Report 01

Critical Langflow Flaws Enable Remote Code Execution

IBM disclosed four vulnerabilities affecting Langflow, an open-source platform for building AI agents and workflows. Two critical flaws, CVE-2026-93680 and CVE-2026-110186, carry CVSS scores of 9.8 and enable authentication bypass and remote code execution without credentials. Additional vulnerabilities, CVE-2026-110193 and CVE-2026-110192, involve authenticated command execution and sensitive information exposure. Versions 1.0.0 through 1.12.8 are affected. A public Metasploit module already demonstrates unauthorized MCP tool enumeration, although it does not execute commands. Langflow 1.13.0 addresses these issues and disables automatic login by default. Organizations should upgrade immediately, restrict API exposure, and review authentication configurations.

IoT botnet Report 02

Google Disrupts Massive Android Botnet

Google disrupted a botnet controlling more than 1.3 million Android devices, primarily TV set-top boxes, through coordinated legal and technical action. Google alleges Chinese manufacturer Videostrong deliberately embedded the x.cpe backdoor into device firmware and sold criminal access. Attackers exploited these devices for advertising fraud, residential proxy services, credential theft, surveillance, and remote command execution. The backdoor could disable Google Play Protect and silently install malicious applications. Google seized command infrastructure and banned Videostrong from certified Android manufacturing. However, infected firmware remains persistent. Organizations should identify affected devices, isolate them, block malicious infrastructure, and replace compromised hardware.

cyber espionage Report 03

DarkBlinders Breaches Middle Eastern Government Systems

Cybersecurity researchers at Dream Research Labs identified an espionage campaign by Iran-aligned DarkBlinders, targeting Israel and Iraq's Kurdistan Region between August and October 2026. Attackers compromised a prominent Israeli individual and a Kurdish government cloud environment. The operation combined credential phishing, impersonated government websites, and malicious software downloads. A counterfeit videoconferencing application named StarkMeet deployed ShelbyLoader V2 and the SHELBYC2 backdoor, enabling persistent remote access and data theft. Researchers identified infrastructure overlaps with UNC5795 and Dust Specter, suggesting possible connections to APT34. Organizations should strengthen phishing defenses, monitor suspicious DLL sideloading, and restrict untrusted software execution.
