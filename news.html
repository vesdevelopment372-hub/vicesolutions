privacy security Report 01

Android 17 Hides Website Visits

Google introduced OS-wide Encrypted Client Hello (ECH) support in Android 17 to strengthen connection privacy. ECH works alongside private DNS to encrypt website domain names that could otherwise be exposed through TLS metadata, preventing network providers and observers from easily identifying visited websites or applications. Android 17 also enables ECH GREASE by default, helping protected and unsupported connections appear similar. Additional security improvements include Local Network Protection requiring permission before apps access nearby devices, default Certificate Transparency, and carrier-controlled 2G disabling. Together, these protections reduce network surveillance, local-network exposure, and risks from cellular downgrade attacks and rogue base stations.

WordPress vulnerability Report 02

Critical WordPress Flaws Enable Takeovers

Researchers disclosed five critical vulnerabilities affecting widely used WordPress components: WPMU DEV Dashboard, Avada, TranslatePress, Pods, and GiveWP. Four flaws carry CVSS 9.8, while the GiveWP vulnerability, CVE-2026-82222, scores a maximum 10.0. Depending on the affected component and configuration, unauthenticated attackers could bypass authentication, obtain administrator credentials, escalate privileges, write malicious PHP files, or execute arbitrary server commands. GiveWP's flaw combines unsafe deserialization with attacker-controlled donation data to achieve remote code execution. Administrators should identify affected installations and apply available security updates promptly to prevent complete website or server compromise.

ransomware extortion Report 03

Berlin Rejects Hackers’ Extortion Demand

Berlin’s state government confirmed an extortion attempt following a compromise of its administrative network and said it will not pay the attackers. Forensic investigators identified data exfiltration between August 7 and 12, with personal or other non-public information potentially affected. Attackers claiming affiliation with Rhysida ransomware alleged stealing 5.79 terabytes containing roughly 1.44 million files, although Berlin has not independently confirmed those figures. Authorities are investigating the perpetrators while continuing forensic analysis. Government departments were reconnected on August 23, and officials said systems supporting the September election remain secure.
