mobile spyware Report 01

Corp MDM Spyware Targets Logistics

A new Android spyware called Corp MDM is targeting logistics companies through fake Google Play pages impersonating CEVA and TKW Logistics. Once sideloaded, the malware requests SMS, telephony, and notification permissions, hides its launcher, and maintains background communication with attacker infrastructure. It steals newly received SMS messages, including potential one-time passwords and account-recovery codes, and allows operators to enable or disable call forwarding remotely. The same infrastructure also hosts credential-phishing pages and Windows malware. Researchers suspect AI-assisted development because of implementation errors and identified possible Armenian or Russian connections, although the operators remain unknown.

malware delivery Report 02

Placeholder Domain Spreads ClickFix Malware

Researchers discovered that third-party[.]com, long used as a placeholder in developer documentation, now serves a malicious ClickFix page to Windows visitors. The domain appears in more than 1,700 public GitHub repositories, including AI-agent skills and MCP server documentation. Victims see a fake Cloudflare verification prompt that manipulates their clipboard and instructs them to execute a command through Windows Run, which retrieves a remote PowerShell payload. The domain has reportedly served the lure since at least June 2026. Researchers recommend replacing non-reserved placeholder domains with IANA-reserved addresses such as example.com to prevent similar abuse.

information stealer Report 03

Hacked Sites Spread Psychedelic Stealer

An active ClickFix campaign is compromising legitimate Ukrainian business websites to distribute a previously undocumented malware called Psychedelic Stealer. Injected pages display fake Cloudflare verification instructions that trick visitors into running a Windows Installer command, which downloads a malicious MSI package. The stealer harvests browser passwords, authentication tokens, cryptocurrency wallet data, and extensive system information while establishing scheduled-task persistence. It can also receive commands for executing additional malware. Researchers recorded campaign activity across 32 countries, although Ukraine accounted for most interactions. Russian-language development artifacts suggest likely Russian operators, but the campaign has not been conclusively attributed.
