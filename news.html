AI Exploitation Report 01

AI Agents Exploit Medical Imaging Zero-Day

AI agents targeting MONAI Label medical imaging software. Attackers exploited CVE-2026-133968, a critical path traversal vulnerability rated CVSS 9.8, affecting versions 0.8.5 and earlier. Using the Cairn AI framework, agents identified arbitrary file-writing capabilities within approximately eleven minutes. Subsequent exploitation enabled Python startup-file manipulation and root access to a university server. Although developers merged a source-code fix, no patched release was available. Organizations should restrict network exposure, enable authentication, enforce least-privilege execution, monitor suspicious Python activity, and validate security fixes before deployment.

AI Vulnerability Report 02

Malicious Webpage Hijacks Meta Muse AI

Security researchers at NebuSec demonstrated a vulnerability chain allowing a malicious webpage to compromise Meta Muse, an autonomous AI assistant. The attack extracted private conversations and stored memories without user approval. Researchers combined a built-in browser vulnerability with a Linux kernel flaw to gain control of the user's isolated cloud machine. This access exposed connected account credentials, saved files, and Sentinel security controls. The laboratory demonstration did not compromise other users or underlying shared infrastructure. Researchers reported the vulnerabilities responsibly, and Muse's team reportedly fixed them. Organizations should strengthen AI agent isolation, browser sandboxing, credential protection, and outbound traffic monitoring.

Critical Vulnerability Report 03

Critical GPGME Flaw Threatens Application Data

The GnuPG project disclosed CVE-2026-129975, a critical double-free vulnerability affecting applications using GPGME versions before 2.3.0. Attackers can exploit unusually long OpenPGP key user IDs to trigger memory corruption, potentially exposing sensitive application data or enabling remote code execution. Affected software includes email clients, XMPP applications, Samba, and Gpg4win. The vulnerability impacts shared libraries, Windows DLLs, and statically linked implementations. No active exploitation has been reported. GnuPG released GPGME 2.3.1, legacy version 1.24.4, and Gpg4win 5.1.2 to address the issue. Organizations should prioritize updates, identify bundled vulnerable libraries, and rebuild affected applications promptly.
