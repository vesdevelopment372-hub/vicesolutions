authentication bypass Report 01

Default Passwords Enable Remote Car Control

Security researchers Shubham Shah and Sam Curry uncovered serious authentication weaknesses affecting connected vehicle services operated by two automakers. Their investigation revealed ForgeRock identity servers exposing an Apache Felix administrative console protected by default admin:admin credentials. By exploiting URL parsing inconsistencies, researchers bypassed perimeter restrictions, executed server-side commands, and modified customer account credentials. Using legitimate mobile application tokens, they successfully unlocked and started authorized test vehicles. Related weaknesses affected systems serving the United States, Canada, and Australia. Both initially reported systems were fixed within two hours. Organizations should eliminate default credentials, secure administrative interfaces, and validate access controls.

cyber espionage Report 02

Bitter Deploys New PapRAT Espionage Backdoor

Security researchers at Fortinet FortiGuard Labs uncovered a cyberespionage campaign by Bitter (APT-C-08) targeting South Asian organizations with a previously undocumented backdoor called PapRAT. Attackers employ three infection chains involving malicious Windows shortcuts, VHDX disk images, WebDAV downloads, and MSI installers. PapRAT, developed in C++ and Rust, supports remote command execution, file theft, directory enumeration, screenshot capture, and file deletion. Its Rust variant additionally supports PowerShell execution. Attackers also deploy WmRAT and abuse legitimate Windows utilities to evade detection. Organizations should monitor suspicious shortcuts, scheduled tasks, PowerShell activity, and unauthorized installer execution to identify potential compromises.

cryptocurrency theft Report 03

Web3Auth Breach Exposes Keplr Wallets

Cryptocurrency wallet provider Keplr confirmed that attackers exploited a security vulnerability in Web3Auth, compromising private keys associated with wallets created through Google or Apple authentication. Web3Auth proactively transferred funds from thousands of vulnerable wallets into secure recovery addresses to prevent further theft. Blockchain researchers identified approximately $6.01 million transferred from over 44,000 wallets, primarily through protective recovery operations rather than confirmed theft. Security firm GoPlus separately estimated at least $1 million stolen. Keplr suspended social login functionality while investigating. Users should avoid depositing additional funds, disregard fraudulent recovery messages, and follow official instructions for securing affected assets.
