identity phishing Report 01

N0va Phishkit Steals Cloud Identities

The N0va phishing kit is targeting organizations across North America and Europe, including government, technology, healthcare, and consulting sectors. Campaigns impersonate trusted services such as Microsoft Teams, SharePoint, OneDrive, DocuSign, Google Drive, Dropbox, Zoom, and Adobe Sign. N0va uses device-code phishing and legitimate authentication flows to make attacks appear credible. After victims authenticate, attackers can capture access and refresh tokens, abuse token exchange or device registration, and establish SSO access. Compromised identities may expose corporate email, files, cloud applications, customer information, and other sensitive resources, potentially enabling fraud, data theft, operational disruption, and wider organizational compromise.

supply compromise Report 02

AI Assistant Hijack Spreads Shai-Hulud

Mandiant reported that an attacker hijacked an active AI coding-assistant session at an unnamed SaaS provider and compromised its software development environment. The assistant recommended attacker-poisoned software, which was accepted and installed through a malicious PyPI package. The attacker then stole GitHub OAuth tokens and deployed the self-spreading Shai-Hulud worm across approximately 100 internal repositories, stealing source code and repository secrets. A package in the company’s official namespace was also poisoned, triggering another infection when downloaded by an employee. Mandiant recommends validating AI-recommended dependencies, protecting long-lived credentials, and routing dependency downloads through controlled internal repositories.

privilege escalation Report 03

Parallels Flaw Grants Root Access

A high-severity vulnerability in Parallels Desktop for Mac could allow a non-administrator user to escalate privileges and execute commands as root. Tracked as CVE-2026-3733 with a CVSS score of 7.3, the flaw involves insecure temporary-file handling in a privileged service. An attacker with local access can exploit predictable file operations and symbolic links to overwrite protected files, ultimately achieving root-level code execution. The vulnerability affects Parallels Desktop versions before 26.2.0, where the issue has been fixed. No evidence of active exploitation has been reported. Users and organizations should update affected installations promptly, particularly on shared or multi-user Mac systems.
