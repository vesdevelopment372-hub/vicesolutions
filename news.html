ransomware exploitation Report 01

Ransomware Groups Exploit Palo Alto MFA Bypass

Palo Alto Networks' Unit 42 confirmed that Qilin and INC ransomware groups are actively exploiting CVE-2026-0257, a CVSS 7.8 authentication bypass vulnerability affecting PAN-OS and Prisma Access. Although patched in May 2026, the flaw enables unauthorized VPN connections and bypasses multifactor authentication. Attackers conduct internal reconnaissance, move laterally using RDP and SMB, and deploy credential theft and ransomware tools. In one incident, attackers compromised VMware vCenter, disabled ESXi security controls, and extracted domain credentials directly from virtual disks, bypassing endpoint protection. Organizations should apply patches, investigate suspicious VPN sessions, and monitor virtualization infrastructure for compromise.

certificate compromise Report 02

Eight eMudhra Certificate Authority Keys Compromised

Mozilla and Google confirmed the compromise of eight intermediate certificate authority private keys belonging to India's eMudhra, potentially enabling attackers to issue fraudulent trusted certificates. Six affected certificates supported TLS authentication, while two were designated for code signing. Chrome and Firefox rapidly blocked the compromised certificates following disclosure on October 17, 2026. Apple, Microsoft, and eMudhra subsequently implemented protective measures. Emergency updates were released for Go, Firefox, NSS, Python certifi, and Rust webpki-roots. The compromise's origin remains unknown, with no confirmed evidence of malicious certificate issuance. Organizations should update affected software and review certificate trust configurations.

remote exploitation Report 03

Critical FortiSIEM Exploit Code Goes Public

Cybersecurity researchers at Horizon3.ai published a proof-of-concept exploit for CVE-2026-106173, a critical CVSS 9.4 path traversal vulnerability affecting Fortinet FortiSIEM. The flaw allows unauthenticated attackers to exploit the gRPC service on TCP port 27918 and overwrite arbitrary files. By combining directory traversal sequences with null-byte injection, attackers can manipulate file paths and replace scripts executed automatically by scheduled tasks, potentially achieving remote code execution. Fortinet addressed the vulnerability in FortiSIEM 7.5.1, while version 7.6 remains unaffected. Administrators should immediately upgrade vulnerable installations, restrict network exposure, and investigate suspicious gRPC activity to prevent compromise.
