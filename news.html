cybercrime investigation Report 01

Windows Device ID Helped Track Hacker

Newly unsealed U.S. court filings reveal that Microsoft’s Global Device Identifier (GDID) played a key role in helping the FBI identify and track an alleged member of the Scattered Spider cybercrime group. Investigators linked the persistent Windows device identifier to Microsoft account activity, IP addresses, and other telemetry records, ultimately tying them to a suspect accused of participating in a 2025 ransomware attack against a U.S. jewelry retailer. The case demonstrates how Windows telemetry can assist digital forensics and law enforcement investigations, while also renewing debate over user privacy, persistent device identifiers, and the extent of operating system telemetry collection.

AI vulnerability Report 02

Rogue Agent Flaw Exposed GitHub Repositories

Security researchers disclosed a critical vulnerability dubbed Rogue Agent affecting GitHub Copilot's integration with the Model Context Protocol (MCP). The flaw allowed a malicious MCP server to manipulate tool invocations and gain unauthorized access to private repositories, source code, secrets, and other sensitive developer data connected to Copilot sessions. By abusing trust relationships between the AI assistant and external MCP tools, attackers could exfiltrate information without directly compromising GitHub accounts. GitHub has addressed the issue with additional validation and permission controls. The incident highlights growing security risks surrounding AI agents, external tool integrations, and developer ecosystems.

AI vulnerability Report 03

GitHub Issue Trick Targets Developers

Security researchers demonstrated that specially crafted public GitHub issues can be used to manipulate AI-powered coding assistants through prompt injection attacks. By embedding hidden instructions within issue descriptions, attackers can influence AI agents reviewing repositories to retrieve sensitive files, expose secrets, generate unsafe code, or perform unintended actions during development workflows. The technique exploits the trust AI assistants place in repository content rather than vulnerabilities in GitHub itself. As AI coding tools become more integrated into software development, prompt injection through trusted collaboration platforms represents an emerging supply-chain risk. Developers should validate AI-generated actions, restrict agent permissions, and keep AI tooling updated with the latest security protections.
