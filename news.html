AI prompt injection Report 01

Amazon Kiro Prompt Injection Leaks Data

Researchers disclosed a prompt injection vulnerability in Amazon Kiro, an agentic AI development environment. Attackers could embed malicious instructions inside repository-controlled content that Kiro interprets as trusted guidance. After a victim opens a crafted workspace file and sends any message to the agent, the instructions can influence Kiro Powers, causing sensitive local workspace information to be incorporated into security-relevant configuration and transmitted externally without an explicit request from the user. The flaw affected Kiro IDE 0.7.45 and required two user actions. Amazon fixed the issue in version 0.8.140 following responsible disclosure.

remote code execution vulnerability Report 02

Next.js Flaws Enable Unauthenticated RCE

Vercel patched two critical vulnerabilities affecting Next.js. CVE-2026-75604 (CVSS 9.0) is a Windows-specific path traversal flaw affecting certain applications using both Pages and App Routers. A separate AVIF image optimization vulnerability (CVSS 9.5) originates in the libheif library used by Sharp and can trigger a heap buffer overflow when processing specially crafted AVIF images, potentially leading to remote code execution. Linux and macOS are unaffected by the Windows flaw, while AVIF exploitation requires AVIF optimization to be enabled. Next.js 15.5.24 and 16.3.3 contain protections, and no active exploitation had been reported.

threat roundup Report 03

296K IoT Botnet Tops ThreatsDay

This week's ThreatsDay roundup highlights a wide range of emerging cybersecurity threats. A major concern is a botnet comprising approximately 296,000 compromised IoT devices, demonstrating how poorly secured connected devices continue to provide large-scale infrastructure for malicious activity. The roundup also covers critical vulnerabilities affecting water and industrial systems, new malware campaigns, exploitation techniques, software supply-chain risks, and security weaknesses involving AI technologies. Together, the incidents show attackers targeting everything from consumer IoT devices to operational technology and enterprise platforms. Organizations should prioritize exposed-asset discovery, rapid vulnerability remediation, strong network segmentation, credential security, and continuous monitoring for unusual device and network behavior.
