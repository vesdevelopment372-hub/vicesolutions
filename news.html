credential phishing Report 01

UAT-11985 Targets Taiwan With AI Phishing

Cisco Talos uncovered a sophisticated spear-phishing campaign by UAT-11985, targeting individuals affiliated with Taiwanese research organizations since mid-2026. Attackers impersonate academic institutions and distribute convincing event invitations, potentially generated using artificial intelligence. Emails contain deceptive registration links, while modified event posters feature malicious QR codes. Victims encounter counterfeit Google Forms pages that redirect them to fraudulent Google login portals. An adversary-in-the-middle (AitM) framework intercepts passwords and multifactor authentication codes, relaying information through HTTP requests and WebSocket connections. The operation demonstrates how AI-assisted social engineering and QR phishing can facilitate Google account takeovers.

privilege escalation Report 02

OpenBSD Root Exploit Bypasses Kernel Defenses

Security researchers at Calif demonstrated a local privilege escalation exploit targeting OpenBSD 7.9 by chaining two kernel vulnerabilities, including a 37-year-old shared-memory integer overflow. The attack manipulates shared-memory reference counters to trigger a use-after-free condition, enabling kernel memory corruption and root-level code execution. Researchers successfully bypassed KARL, SMAP, and SMEP security protections without requiring an information disclosure vulnerability. OpenBSD addressed the issues through security patches 018 and 026, released in September 2026. Public proof-of-concept exploit code is available on GitHub. No active exploitation has been reported, and administrators should apply updates using syspatch.

supply compromise Report 03

AOMEI Update Servers Deliver Malicious Backdoor

Google Threat Intelligence Group and ManageEngine uncovered a supply chain attack targeting AOMEI Backupper between May and July 2026. Threat group UNC7017 modified update configuration files for five-to-ten-minute intervals, delivering malicious payloads through legitimate update mechanisms. The attack deployed CROSSROAD and SHINYROAD malware, enabling persistent remote access through DLL sideloading and scheduled tasks. Researchers identified affected organizations across 11 countries, including India and the United States. Attackers also abused WebDAV connections to capture NetNTLMv2 authentication responses. Although AOMEI reported securing its servers, previously infected systems require investigation, credential protection, and malware removal.
