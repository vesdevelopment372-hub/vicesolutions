container security vulnerability Report 01

Dell CSM Flaws Enable Kubernetes Takeover

Dell patched six critical vulnerabilities affecting Container Storage Modules (CSM). Two flaws, CVE-2026-63688 and CVE-2026-63692, carry maximum CVSS 10.0 scores and can allow unauthenticated attackers to obtain storage administrator credentials or administrative privileges. Another vulnerability, CVE-2026-67269 (CVSS 9.9), can let a low-privileged attacker escalate to root and potentially compromise every node in a Kubernetes cluster. Additional flaws involve hard-coded credentials, JWT signing secrets, and RBAC manipulation. All CSM versions before 1.17.0 are affected, and Dell recommends upgrading to 1.18.0 and rotating JWT signing secrets.

AI security vulnerability Report 02

GitLab AI Gateway Flaw Enables Command Execution

GitLab patched CVE-2026-90970, a critical CVSS 9.9 vulnerability affecting self-hosted GitLab AI Gateway deployments. A logged-in user with Duo Agent Platform access could submit a specially crafted custom-flow configuration that escapes the prompt-template sandbox and executes arbitrary commands on the gateway. This is particularly sensitive because self-hosted gateways contain JWT signing keys and connect to GitLab instances and organizational AI providers. The issue affects gateway versions from 18.1.6 through vulnerable 19.x releases. Fixes are available in 19.2.4, 19.3.2, and 19.4.1. No active exploitation has been reported.

cyber espionage Report 03

Antino Backdoor Hides C2 in Microsoft 365

Cisco Talos uncovered Antino, a previously undocumented Rust-based Windows backdoor deployed by China-nexus threat actor UAT-11587 against government and policy organizations across Asia, including India, Taiwan, Pakistan, Thailand, the Philippines, Cambodia, and Myanmar. The campaign uses tailored spear-phishing and fake Gmail attachment previews before deploying Antino through DLL sideloading. Instead of conventional attacker-controlled C2 infrastructure, the malware uses Outlook for command exchange and OneDrive for heartbeat and file transfers through Microsoft Graph. Antino supports reconnaissance, PowerShell and shell execution, file transfers, persistence, process enumeration, and in-memory shellcode execution.
