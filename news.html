account takeover Report 01

Keycloak Flaw Enables Account Takeover

A critical Keycloak vulnerability, CVE-2026-18963 (CVSS 9.1), could allow an unauthenticated remote attacker to take over any user account without interaction. The flaw results from improper state validation in the reset-credentials authentication flow. A specially crafted request can move the authentication session directly to the password-update stage, bypassing the email action token normally required for password recovery. Successful exploitation could compromise even administrator accounts. Keycloak fixed the issue in 26.7.2, while Red Hat released corresponding RHBK updates. No exploitation has been observed. Administrators unable to patch immediately should disable Forgot password across all realms.

malware distribution Report 02

Fake Minecraft Clients Spread Weedhack

Security researchers uncovered an active Weedhack malware campaign targeting Minecraft players through fake client and mod websites. Attackers use SEO poisoning to push malicious sites above legitimate projects in search results and distribute infected JAR files through Discord, MediaFire, GitHub, and gaming communities. Some fake websites closely copy legitimate projects, while one was created using an AI-powered website builder. Once executed, Weedhack collects system information, creates Microsoft Defender exclusions, and steals sensitive data. McAfee recorded more than 6,300 attempts to access associated malicious sites. Users should download Minecraft clients and mods only from verified sources.

malware loader Report 03

WordListLoader Delivers Amatera Through Steganography

Security researchers uncovered WordListLoader, a new malware loader used to deliver the Amatera information stealer through a multi-stage infection chain. The campaign uses steganography to conceal encrypted malicious payloads within apparently harmless image files, helping the malware bypass conventional security scanning. After execution, WordListLoader extracts and decrypts the hidden payload in memory before launching Amatera, reducing artifacts available for endpoint analysis. The stealer can collect browser credentials, authentication cookies, cryptocurrency wallet information, system details, and other sensitive data from infected machines. Organizations should strengthen behavioral endpoint monitoring, inspect suspicious script and image-processing activity, restrict untrusted downloads, and monitor endpoints for credential-stealing behavior.
