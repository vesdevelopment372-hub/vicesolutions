privilege escalation Report 01

USB Auto-Install Grants Windows SYSTEM Access

Security researchers demonstrated Plug And Pwn, an attack technique that abuses Windows Plug and Play (PnP) auto-installation and weaknesses in signed third-party device software to gain SYSTEM privileges on a fully updated Windows 11 machine. The physical attack chains emulated Sierra Wireless and Sony FeliCa devices to manipulate DNS, exploit path traversal, plant a malicious DLL in System32, and execute it with SYSTEM privileges. Researchers also demonstrated a remote variant through RDP USB redirection, although this functionality is disabled by default. Administrators should restrict unnecessary device installation, keep USB redirection disabled, and enforce device-installation policies.

AI cybersecurity Report 02

OpenAI Launches GPT-5.6 Cyber

OpenAI announced GPT-5.6 Cyber, a specialized model designed for advanced cybersecurity tasks such as vulnerability research, secure code analysis, threat investigation, and defensive security workflows. The model builds on GPT-5.6 with stronger cyber reasoning capabilities while incorporating safeguards intended to restrict harmful or unauthorized offensive use. OpenAI also introduced expanded cybersecurity evaluations and monitoring to assess how advanced models perform on dual-use security tasks. The release highlights the growing role of specialized AI in accelerating vulnerability discovery and security operations, while emphasizing the need to balance increasingly capable cyber automation with controls that reduce misuse.

mobile security vulnerability Report 03

Malicious SIM Cards Can Hijack Smartphones

Security researchers demonstrated that a malicious or compromised SIM card can abuse the trusted communication channel between the SIM and smartphone to perform attacker-controlled operations. By sending specially crafted SIM Toolkit commands, the SIM can interact with device functionality without relying on a conventional malicious application. Depending on the handset and available permissions, attacks could manipulate network-related actions, trigger communications, redirect users, or expose sensitive information. The research highlights how SIM cards represent a largely overlooked attack surface because they operate as trusted components inside mobile devices. Mobile vendors and carriers should strengthen validation of SIM-originated commands and restrict unnecessary SIM Toolkit capabilities.
