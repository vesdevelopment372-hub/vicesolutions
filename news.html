critical vulnerability Report 01

Adobe Fixes Three CVSS 10.0 Flaws

Adobe released security updates addressing multiple critical vulnerabilities in ColdFusion, Commerce, and Campaign Classic, including three flaws rated CVSS 10.0. CVE-2026-48362 is an OS command injection vulnerability in ColdFusion, while CVE-2026-71398 and CVE-2026-27302 are authorization flaws in Campaign Classic that can lead to arbitrary code execution. Adobe assigned ColdFusion and Campaign Classic updates a Priority 1 rating because of their higher exploitation risk. No active exploitation has been reported, but administrators are advised to install the patches within 72 hours and prioritize exposed enterprise systems.

zero-day exploitation Report 02

Lazarus Exploits Windows Zero-Day

North Korea-linked Lazarus Group exploited CVE-2026-68820, a Windows AFD.sys privilege-escalation vulnerability, as a zero-day in its Operation Dream Job espionage campaign. Attackers targeted defense and aerospace professionals in France, Germany, Brazil, and India using convincing fake job opportunities and trojanized PDF software. After initial infection, the exploit elevates privileges to SYSTEM, allowing the attackers to deploy the Troy, MISTPEN, and ForestTiger backdoors and evade security controls using an updated FudModule rootkit. Microsoft patched the vulnerability in its August 2026 security updates, making immediate patch deployment a priority.

AI data exposure Report 03

AI API Flaw Exposes Hidden Reasoning

Researchers disclosed a flaw affecting reasoning APIs from OpenAI, Anthropic, and Google that allowed encrypted reasoning blocks to be replayed across sessions, users, and compatible models. A weaker model could then act as a decoder and reconstruct hidden reasoning generated by a stronger model. Researchers analyzed 6,708 public agent trajectories and decoded 315,320 reasoning blocks, discovering hundreds of privacy artifacts, including API keys, passwords, access tokens, and private keys. The technique could also enable hidden prompt injection and model distillation. The providers received the findings, and researchers report that the demonstrated extraction attacks stopped working after mitigations.
