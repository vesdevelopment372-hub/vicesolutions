domain abuse Report 01

Hackers Spend $7 Million Buying Trust

DNS researchers uncovered a large cybercrime ecosystem abusing expired “dropcatch” domains that retain reputation, backlinks, search results, and residual traffic from their previous owners. One operation, tracked as Sable Squirrel, has reportedly spent nearly $7 million acquiring such domains and controls more than 10,000 of them. The infrastructure supports illegal sports streaming, gambling promotion, traffic redirection, and malware command-and-control. Researchers identified about 31,000 malware samples, including Quasar RAT, AsyncRAT, DCRat, Remcos RAT, and ransomware-related artifacts, communicating with Sable Squirrel infrastructure. The campaign demonstrates how historical domain reputation can be weaponized to bypass trust-based security controls.

remote code execution vulnerability Report 02

SAP Commerce Cloud Flaw Enables RCE

SAP disclosed CVE-2026-58231, a critical vulnerability affecting SAP Commerce Cloud that could expose vulnerable enterprise environments to remote compromise. The flaw stems from unsafe handling of attacker-controlled input and could enable unauthorized code execution under affected configurations. Successful exploitation may allow threat actors to access sensitive commerce data, manipulate application functionality, establish persistence, and potentially move deeper into connected enterprise systems. Given SAP Commerce Cloud's role in business-critical e-commerce operations, administrators should prioritize the vendor's security updates, restrict unnecessary external access, review application and authentication logs, and investigate affected systems for indicators of unauthorized activity.

privacy vulnerability Report 03

macOS Screen Sharing Exposes Sensitive Data

Security researchers disclosed a vulnerability affecting Apple macOS Screen Sharing that could allow sensitive content to remain visible during remote screen-sharing sessions even when applications rely on macOS privacy protections to prevent capture. The weakness creates a risk that confidential information displayed by password managers, authentication tools, enterprise applications, or other protected software could be exposed to a remote viewer. The issue highlights how screen-sharing functionality can undermine application-level privacy boundaries when operating-system protections are inconsistently enforced. Users and organizations should install Apple's latest security updates, limit Screen Sharing access to trusted users, disable unnecessary remote access, and avoid displaying sensitive information during active sharing sessions.
