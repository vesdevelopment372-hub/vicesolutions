Critical Vulnerability Report 01

Hackers Exploit Critical ASP.NET Security Flaw

Google Mandiant researchers discovered active exploitation of CVE-2026-131914, a critical insecure deserialization vulnerability affecting the discontinued Idunno.AntiCsrf library for ASP.NET WebForms. Rated CVSS 9.3, the flaw allows unauthenticated attackers to execute arbitrary code through a single malicious HTTP POST request. Vulnerable versions include 0.9.1.0 and 0.9.1 Beta. Exploitation occurs because the library processes untrusted CSRF tokens without cryptographic verification, potentially compromising IIS servers. No official patch is available because the project is abandoned. Organizations should replace the library, audit application dependencies, inspect suspicious IIS requests, rotate exposed credentials, and investigate unauthorized server modifications immediately.

Code Injection Report 02

Critical Binary-Parser Flaw Enables Code Injection

A critical code injection vulnerability, CVE-2026-134814, affects binary-parser versions before 2.3.1, carrying reported CVSS scores of 9.2 and 8.1. Attackers controlling parser definitions can inject malicious JavaScript through improperly validated string options, including length, key, tag, offset, and aliases. The injected code executes within the Node.js process during parser compilation, potentially compromising application security. The vulnerability represents an incomplete fix for CVE-2026-1245, previously addressed in January 2026. Parsing untrusted binary data using trusted parser definitions remains unaffected. Organizations should upgrade to version 2.3.1 or later, restrict untrusted parser configurations, and audit application dependencies for exposure.

Critical Vulnerability Report 03

Critical ScreenConnect Flaw Under Active Exploitation

Huntress researchers identified active exploitation of CVE-2026-84869, a critical ConnectWise ScreenConnect vulnerability rated CVSS 9.9. The flaw allows malicious remote guests to transfer and execute files on technicians' computers without confirmation. Attackers deployed malicious batch scripts, contacted Telegram bots, and installed rogue ScreenConnect clients to establish unauthorized remote access. Researchers observed over 688,000 suspicious file execution requests across 42 servers, highlighting widespread exploitation attempts. Compromised MSP workstations could expose customer credentials and remote management infrastructure. Organizations should upgrade ScreenConnect clients to version 26.6.5 or later, restrict file transfer permissions, investigate suspicious sessions, and rotate potentially compromised credentials.
