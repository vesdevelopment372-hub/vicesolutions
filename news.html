botnet malware Report 01

Evooo1Bot Turns Edge Devices Into Proxies

Researchers uncovered Evooo1Bot, a previously undocumented Linux botnet active since July 2026 that combines Mirai's DDoS capabilities with an expanded exploitation toolkit. It targets internet-facing routers, firewalls, IP cameras, Kubernetes systems, and other devices through numerous known vulnerabilities and SSH brute-force attacks. Once infected, devices can become SOCKS5 proxy nodes, allowing attackers to relay malicious traffic through victims' IP addresses, access internal networks, or build distributed proxy infrastructure. Evooo1Bot also supports credential sniffing, remote shells, persistence, encrypted C2 communications, file transfers, and multiple DDoS methods.

AI security Report 02

MCP Servers Put Enterprise Secrets at Risk

The growing adoption of Model Context Protocol (MCP) introduces new security risks because MCP servers often hold credentials required for AI agents to interact with databases, cloud infrastructure, internal documents, and APIs. Secrets may be exposed through plaintext configuration files, environment variables, credential sprawl, excessive permissions, malicious MCP servers, and prompt injection. A compromised MCP server can therefore expose both sensitive information and the ability to perform actions on connected enterprise systems. Organizations should centralize secret management, use short-lived credentials, enforce least privilege, require human approval for sensitive operations, maintain MCP inventories, and continuously audit agent activity.

mobile vulnerability Report 03

VoLTE Call Exploit Gains Android Kernel Access

Researchers disclosed a two-stage exploit chain affecting Unisoc modem firmware that can achieve full Android kernel-level code execution through a malicious VoLTE video call. The attack first exploits a previously disclosed modem remote code execution flaw, then abuses insufficient hardware isolation between the modem and application processors to modify Android kernel memory. Exploitation requires an attacker-controlled private 4G network and the victim to answer the video call. Affected chipsets include those found in devices such as the Motorola E13, Realme C33, and Xiaomi Redmi A5. No vendor patch or mitigation was available at disclosure.
