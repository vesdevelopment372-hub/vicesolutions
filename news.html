Microsoft Disrupts Three Global Phishing Networks

Microsoft, Health-ISAC, and international cybersecurity partners disrupted three major phishing kits: CoGUI, Haozi, and Iron Man System. Since January 2026, these platforms facilitated over one billion phishing emails and SMS messages, targeting more than 75,000 organizations across 150 countries. The Chinese-speaking cybercriminal ecosystem used YAM Store to distribute phishing tools and compromised cloud infrastructure. Attackers impersonated financial institutions, government agencies, and logistics companies to steal credentials and financial information. Investigators identified approximately 17,000 malicious domains associated with the kits. The court-authorized operation targeted infrastructure supporting phishing campaigns, aiming to reduce widespread financial fraud and credential theft.

active exploitation Report 02

Cisco Email Gateway Flaw Actively Exploited

Cisco confirmed active exploitation of CVE-2026-76519, a critical CVSS 9.8 vulnerability affecting Secure Email Gateway appliances. The flaw allows unauthenticated attackers to send specially crafted email attachments that write arbitrary files to the operating system, potentially enabling root-level command execution. Exploitation requires the File Reputation service to be enabled and Content Scanner Tools versions older than 25.3.0.5525. Cisco discovered the vulnerability internally and identified attacks during October 2026. Security fixes are available in AsyncOS 15.5.5-014 and 16.5.0-780. Administrators should verify scanner versions, apply updates, investigate compromise indicators, and rebuild compromised virtual appliances.

active exploitation Report 03

Hackers Backdoor Nextcloud Through Critical Flaw

Cybersecurity researchers confirmed active exploitation of CVE-2026-110447, a critical command injection vulnerability affecting the Collabora Online Built-in CODE Server app for Nextcloud. The flaw allows unauthenticated attackers to execute commands when the local document server is stopped or restarting. Attacks observed since September 10, 2026, deployed PHP web shells and searched compromised systems for credentials, password databases, and cryptocurrency wallets. Versions before 26.4.303 are vulnerable, while standalone Collabora servers remain unaffected. Administrators must update or remove the affected app, as simply disabling it provides insufficient protection. Investigating suspicious PHP files and access logs is recommended.
